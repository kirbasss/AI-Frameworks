# Прикладные системы и фреймворки искусственного интеллекта

Пять лабораторных работ по классификации и регрессии с KNN, линейными моделями, решающим деревом, случайным лесом и градиентным бустингом. Задание курса находится в [`doc/task.docx`](doc/task.docx).

## Задачи и данные

- **Классификация:** определить по демографическим и личностным признакам, сообщал ли респондент об употреблении каннабиса за последние 12 месяцев. Источник: [UCI Drug Consumption (Quantified)](https://archive.ics.uci.edu/dataset/373/drug-consumption-quantified).
- **Регрессия:** предсказать число новых обращений 311 о граффити в районе Чикаго на следующую неделю. Источник: [Chicago Graffiti Removal Historical](https://data.cityofchicago.org/Service-Requests/311-Service-Requests-Graffiti-Removal-Historical/hec5-y4x5).

Исходные датасеты скачиваются по ссылкам выше в каталог `datasets/`. Каталог не включён в репозиторий.
