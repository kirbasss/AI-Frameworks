# Прикладные системы и фреймворки искусственного интеллекта

Лабораторные работы по классическим алгоритмам машинного обучения. Сравниваем модели scikit-learn и собственные реализации с исходными настройками и после проверки гипотез улучшения.

**Классификация:** по демографическим и личностным характеристикам определяем, сообщал ли респондент об употреблении каннабиса за последние 12 месяцев.

**Регрессия:** прогнозируем число новых обращений 311 о граффити в районе Чикаго на следующую неделю.

## Запуск

1. Открыть ноутбук в Google Colab через меню «Файл», «Открыть блокнот», вкладка GitHub или загрузить файл с компьютера.
2. Выбрать Python 3 с CPU и выполнить ячейки сверху вниз.
3. Дождаться загрузки данных и расчётов. Исходный CSV Chicago занимает около 268 МБ.

Данные автоматически скачиваются в `datasets/`; существующие файлы используются повторно.

Ноутбуки самодостаточны: общий код и собственные алгоритмы находятся внутри ячеек, подключать файлы `src` в Colab не требуется. Собственные деревья и ансамбли используют ограниченный набор порогов по обучающим квантилям. Лес может считать CV несколько минут на CPU; GPU не нужен. В конце каждой работы находятся сохранённые оценки и выводы по фактическому запуску.

## Результаты для итогового сравнения

Каждая работа сохраняет JSON в [`results`](results). В нём находятся восемь тестовых оценок, параметры моделей, описания предобработки, таблицы CV с метриками каждого фолда, средними и стандартными отклонениями, контрольные суммы данных и разбиений. После запуска в Colab JSON можно скачать из каталога `results` и сохранить в репозитории.

Итоговый ноутбук объединяет JSON всех работ и проверяет совпадение данных, целей, частей разработки, тестов и CV-фолдов. Подготовка признаков настроенных моделей может различаться и указывается в результатах. Общий исходный набор информации позволяет сравнить бейзлайны, а настроенные варианты — решения с выбранной предобработкой. Новый подбор или обучение для построения сводных таблиц не требуются.

## Датасеты

### Drug Consumption (Quantified)

[Источник: UCI](https://archive.ics.uci.edu/dataset/373/drug-consumption-quantified).

Набор содержит **1885 анкет**. Используем 12 демографических и личностных признаков: возраст, пол, образование, страну, этническую принадлежность, пять личностных шкал, импульсивность и поиск ощущений. ID и ответы о других веществах исключаем.

Ответ о каннабисе преобразуем в два класса: `CL3–CL6` — употребление за последние 12 месяцев, `CL0–CL2` — ранее или никогда. Получаем 999 положительных и 886 отрицательных ответов. Тест содержит 20% наблюдений, `random_state=42`, со стратификацией. На остальных 80% сравниваем гипотезы и параметры с помощью `StratifiedKFold`: три части, перемешивание и то же случайное состояние. Масштабирование обучается отдельно внутри каждого фолда.

Исследуем связь анкетных характеристик с сообщённым опытом употребления. Полученный класс не описывает будущее поведение человека.

### Chicago Graffiti Removal — Historical

[Источник: Chicago Data Portal](https://data.cityofchicago.org/Service-Requests/311-Service-Requests-Graffiti-Removal-Historical/hec5-y4x5).

В исходном наборе около **1,05 млн обращений**, последняя дата создания — 18 декабря 2018 года. Исключаем повторные номера, помеченные дубликаты, некорректные даты и неизвестные районы. По дате создания строим недельные счётчики для 77 Community Area, включая недели без обращений.

Одна строка модели — район и прогнозируемая неделя. Признаки описывают прошлые обращения и сезонность. После подготовки годовой истории получаем **27 797 строк**. Часть разработки охватывает 2012–2017 годы. Временная CV состоит из трёх фолдов: обучение до 2015 года с проверкой на 2015-м, до 2016-го с проверкой на 2016-м и до 2017-го с проверкой на 2017-м. Тест — недели с началом в январе–ноябре 2018 года. Последняя такая неделя заканчивается 2 декабря. Данные 2011 года нужны для расчёта истории.

В исходном KNN используем район и короткие агрегаты истории. В настроенном варианте добавляем сезонность, стандартизацию числовых признаков и one-hot района, подбираем число соседей и веса по среднему MAE временной CV. Параметры преобразований обучаются без тестовых данных.

Каждую неделю прогнозируем следующий недельный счётчик с учётом уже поступивших сообщений. Практическая задача — оценка нагрузки на службу. Число зарегистрированных обращений отличается от числа всех случаев граффити.
